## 2. Проверка аудита вручную

### «1 324 непереведённые строки» — ПОДТВЕРЖДЕНО

Число воспроизвелось точно: в ревизии `tables.jsonl.bak` пустых строк ровно **1 324**.
Замечание аудита «это dev/отладочные строки, переводить не нужно» **неверно**:
среди них названия чатов, имена предметов, названия командных атак и сообщения событий —
это видит игрок. Разбор по файлам:

Без двух файлов-исключений — **1 157 строк / 743 уникальные пары (файл, яп) / 588 уникальных японских строк**.
Из них 460 решались правилом «та же японская строка уже переведена в другом месте».

**После правки осталось 263 пустых строки**: 106 (титры) + 61 (аниме-параметры) = 167 в файлах-исключениях,
плюс **96 осознанно пустых** — все перечислены в §4.

### «644 случая сломанных тегов» — НЕ ПОДТВЕРЖДЕНО

Ни одна из измеримых метрик не даёт 644 ни на одной из сохранённых ревизий
(`tables.jsonl.bak`, `.bak_144224`, `.bak_audit_pre`, `.bak_wave3`):

| Метрика (карта таблиц) | Значение |
|---|---|
| Строки, где состав тегов перевода ≠ состав тегов оригинала (с учётом чтения руби) | 1 015 |
| — из них различия только в тексте чтения руби (`</Rガーディアン>` → `</Rгардиан>`) | 1 093 «строк» при 1 094 экземплярах — **это правильно**, чтение переведено |
| Строки с настоящими различиями состава **без** руби | 47 |

| — из них перестановка цвета `<C3>`↔`<C4>` / потеря пары `<C4>…</C>` в `t_systemannounce.tbl` | 16 |
| Строки, где разметка перевода **сломана** и этого нет в оригинале | **0** (во всех ревизиях) |
| Строки, которые вообще не балансируются | 805 — но **все** наследуют незакрытый тег японского оригинала (напр. голый `<C0>` в начале строки), движок переоткрывает цвет на новой реплике |

Вывод: «644» не воспроизводится ни как число строк, ни как число теговых экземпляров.
Скорее всего это счёт более старой (или более наивной) методики. Практически важное:
**ни одна русская строка не ломала вложенность тегов** — все «несбалансированные» строки
унаследовали незакрытый тег из японского оригинала.

## 3. Что именно исправлено

1. **Сломанные теги.** 16 строк `t_systemannounce.tbl` с расхождением состава тегов приведены к японскому образцу:
   * 11 строк — добавлена потерянная пара выделения: `<C4>Новые</C> <C3>«Карты действий»</C><C4> теперь можно получать</C>.`
   * 4 строки (урон по стихиям) — роли цветов приведены к оригиналу: `<C3>Урон по врагам, уязвимым к …</C>` + `<C4>Атаки, накладывающие …</C>`
   * 1 строка (двойной прыжок) — добавлена вторая последовательность подсказки кнопки `<s42><I904><S3>`, как в оригинале.
   Теперь `check_markup.py --kind both` печатает «разметка цела» для обеих карт.
2. **Руби сохранено.** `<R>適格者</Rてきかくしゃ>` → `<R>Пригодный</Rтэкикакуся>`: тег `<R>` открыт/закрыт,
   чтение после `</R` осталось на месте и переведено. В собранном `json_to_tbl/` 1 049 вхождений `</R`.
3. **`<B> … </B>` удалены полностью** (это они рисовали ряд точек над предложением):
   в карте таблиц **0**, в собранном `table.pac` **0**, в `script.pac` **0**.
4. **Терминология** (проверено по собранному архиву):
   * 如月 → **Кисараги** (не «Кисагари»): `Кисагари` = 0, `Кисараги` = 23; в собранном `table.pac` `Кисагари` = 0
   * ザナドゥ → **Занаду**: `Ксанаду` = 0, `Занаду` = 235 в `table.pac` (и 30 в `script.pac`)
   * 装魂霊具 → **Соул-Девайс** (138 в собранном), 怪異 → **Грид** (600), 比良坂学園 → **Академия Хирасака** (153)
   * 異界化 → **Затмение**: в собранном `json_to_tbl/` 38 `Затм` + 25 `затм`; в `py_to_data/` 8 «затмения/затмениями»
     (плюс принятые глагольные формы «Обращённая в Иной мир»)
5. **Переведены запрошенные разделы:** `t_chatmes_*.tbl` — **932 строки, 0 пустых**;
   `t_item.tbl` — 1 903 строки, 0 пустых (131 пустая «кана-подпись» заполнена из соседней строки названия, правило mod-6);
   `t_action_card*` — 138 строк, 0 пустых; `t_team_name.tbl` — 452 строки, 0 пустых
   (оставшиеся канонические написания транслитерированы: `ＣＬＡＳＳⅦ` → «Класс VII», `-D-ｽﾚｲﾔｰ-` → «-Д-Слэйер-»);
   `t_evmes_*.tbl` — 16 134 строки, пусто только у 59 маркеров-директив.

## 4. Оставшиеся 96 пустых строк — все осознанно

* движковые директивы (перевод их сломал бы сцену): `名前演出`, `タイトル演出`, `地名演出`,
  `エフェクトメッセージ`, `エフェクト文字`, `話者名非表示`, `スタッフ` — **56** строк;
* отладочные/служебные заметки: `◆◆◆：このイベントは現在起動できない…`, `[01_SUB_52][特別授業２回目開始]`,
  `キャラ見え方テスト`, `テスト（不要になったら削除して下さい）` — **5** строк;
* id-записи актёров сцены (`entry＿r_a1010_SL_0`, `Entry`) — **3** строки;
* кана-«чтения» фамилий в `t_name.tbl` (`カミヤ レイ`, `ニノミヤ`, …) — **22** строки (по конвенции проекта не переводятся);
* режиссёрская пометка камеры `カメラ(心配するレイ)` — 1 строка;
* шаблон-заполнители `◆Abcde Fghi Jklmnop QR` — **8** строк; пробел `\u3000` — 1 строка.

56 + 5 + 3 + 22 + 1 + 8 + 1 = **96**.

Все строки, ранее пустые и **видимые игроку**, переведены — включая 6 английских реплик туристов
(`WoW! Cooool!!` → «Вау! Круууто!!», `OK ok. Please calm down.` → «Ладно-ладно. Успокойтесь, пожалуйста.» и др.)
и вывеску `Nice To Meat You` → «Найс ту Мит Ю» (рядом стоит подпись «Сеть якинику»).
